# M16: The suite's source checks read the whole extension, not one file

**Status:** done (2026-08-20, PR #16 https://github.com/jmgirard/quarto-index/pull/16)

**Goal:** Every check that reads the filter's source reads the extension's whole Lua source set, so a definition moving between files cannot turn a check into a vacuous pass.

**Outcome:** `tests/filtersrc.py` is the one recursive enumeration of the extension's `.lua` files, rooted at `QI_EXT_DIR` and refusing an empty set. The twelve source-reading scanner bodies live one per file under `tests/scans/`, invoked through `run_scan` in `tests/run-tests.sh` — the single place each one's environment and arguments are written. Three of the twelve were `sed` constant reads and are now scans like the rest, gaining an exactly-one pin `sed` could not give them. Under `--self-test`, `tests/movedefs.py` builds a scratch extension with definitions relocated into `modules/moved.lua` and `tests/plantdefect.py` plants a defect of the kind each scan names, which the scan must fail on, naming it. `tests/byte-diff.sh` is deleted. The run refuses an ambient `QI_EXT_DIR`, since renders resolve the filter through the `examples/_extensions` symlink regardless of it. 195 checks plain, 230 under `--self-test`.

**Decisions:** the T3 mechanism, recorded twice as executing it corrected it — the scanner bodies lift out of their heredocs into files rather than being extracted as functions (three produce values consumed hundreds of lines later, so moving them would change evaluation order), and the planned `--source-scan-check` re-entry flag became the `run_scan` dispatcher, because seven scans take a pin the suite defines deep in the run body and a re-entry would need a second copy of them. Cross-cutting: D-004.

**Review:** three-lens fan-out. The blame-history and prior-review lenses reported no findings. The diff-bug lens returned thirteen ranked; nine were fixed on the branch — the two-enumerations duplication against AC2's "one" and the three findings that dissolved with it, three unreachable guards, an ambient-`QI_EXT_DIR` hole the milestone itself opened, `filtersrc.lines()`'s phantom trailing line, `movedefs.block()`'s silent partial move, and the DESIGN.md harness paragraph. F3, F7, F8 and F11 were absorbed into the acceptance-suite hardening row, with the blame-history lens's note on `mark-report-keys.py`'s weaker `warn(` regex. A stray `examples/demo.log` swept in by `git add -A` was removed. Nothing retired at hygiene; M16's shape extended the standing lesson on proving a check discriminating.
