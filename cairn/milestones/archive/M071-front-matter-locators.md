# M071: A front-matter mark in an HTML book chapter files one locator, to the chapter's page

**Status:** done (2026-09-03, PR #71 https://github.com/jmgirard/quarto-index/pull/71)

**Goal:** In an HTML book, a mark written in a chapter's YAML front matter is filed by that chapter's own render as the recovery route files it — once, with a locator that links to the chapter's page and nothing after it — so the index prints no link into a fragment the chapter's page does not carry.

**Outcome:** A tagging pass (`TagSpan`/`TagPandoc` in `_extensions/index/modules/passes.lua`, wired ahead of `CollectSort` in `index.lua`) walks the document's metadata alone and sets `META_MARK_ATTR` (`data-qi-meta`, `core.lua`) on every index span there, its element hook discarding an author's forged copy first; in an HTML render it also takes the index class off every span inside Quarto's top-level `#quarto-meta-markdown` div (`META_REFLECTION_ID`), the reflected copies that never reach the page. The emit pass reads the tag off in every format and, under `html_book_chapter` (`is_html()` and `doc.meta.book`, settled in `Reset`), files a tagged mark with `page_locator = true` and no anchor; `build_record` carries the flag and `book_marks` gives such a mark the reading chapter's own href too. A single document is untouched. Suite: the M070 record leg renders `seven.qmd` as well and `M070_SECTIONS_RECORDED` is re-derived (front-matter rows page-only, `Ingot` page then fragment, `Jetsam` and `Oakum` added); `examples/front-matter.qmd` is the single-document control with title-block containment checks; `tests/fragments.py resolve` walks every locator of every index section in four captures; an own-chapter leg; `data-qi-meta` joins the residue sweep with its own plant; five filter/fixture plants and the reader plants shown red — 654 checks plain, 1228 with `--self-test`. `site/books.qmd` (ledger 31 → 32), `CHANGELOG.md`, DESIGN's architecture and recovery sections; KI232 and KI233 struck.

**Decisions:** D-048, written at plan: a front-matter mark in an HTML book chapter files one locator, the chapter's page, narrowing D-047's locator-count consequence.
