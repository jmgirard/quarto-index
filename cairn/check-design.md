- 2026-08-16 (M01): A green suite is evidence about what it covers, not about the code. Three review passes each found defects the passing suite did not reach; probe the interaction that actually broke, not a simpler cousin of it.
- 2026-08-16 (M01, consolidated M14 from M06 and M08): Prove a check discriminating by reverting the fix and watching it fail — a passing check may be one that cannot fail (three here passed against a filter emitting no sort field at all, a control implied by earlier assertions, and a rule its own comment disclaimed), and a grep matching any instance of a warning fences nothing. Commit the fix first: `git checkout -- <file>` inside the probe restores HEAD and destroys uncommitted work. M15 adds a third shape: the check's own pattern quietly matching less than it reads as — `re.findall` over alternating groups returns `''` for the branch that did not match, and `\seealso?` requires the literal `seeals`. M16 adds a fourth: the check's DOMAIN silently emptying — a scan reading source out of one named file goes vacuous the moment the definition moves to another, and nothing about it looks different. M17 adds a fifth: the REPAIR for a vacuous domain going vacuous itself — replacing a hand list of fixture filenames with a script that scans five named front-matter keys is the same shape one layer down, while the comment beside it says the hand list is gone. Where a copy has to be complete, hold it against a rendering made where nothing was copied at all. Probe a spliced defect of each kind the check claims to catch, and where the check sweeps a domain, probe the domain moving too. M18 adds a sixth: a grep key shared by two messages counts neither, and a key the run passes but the key-distinctness scan does not receive is held to nothing — every zero-expectation control resting on it then passes vacuously. Pass that scan every key the run uses, never a fixed slice. M23 adds a seventh, one layer up: a scan that pins NAMES and SHAPES in source certifies a property it never asserts — twice here it counted a call or matched an indentation-anchored line while the property was about WHERE the code sat, and a tree breaking it exited 0. Six such gaps surfaced across two review rounds, each only by someone building the broken tree by hand. Where the property is positional, assert it by breaking it and rendering: a render cannot pass a tree whose render fails. And a criterion promising what a checker asserts binds the checker, not the deliverable — M25 adds that such a criterion, greping a file set, is matched by COMMENTS too: a comment quoting the old spelling the criterion forbids fails it as surely as a live call. M25 adds an eighth shape as well: a plant of the wrong KIND. Narrowing six scans from first-match to exactly-one left the probe planting a changed VALUE, which a first-match reader fails on exactly as an exactly-one reader does, so the new clause could have been reverted with the suite green; the defect a count clause needs planted is a second definition. M29 adds a ninth: a probe that PLANTS its defect with two edits passes on either one — here a second `sed` meant to append the moved clause also rewrote the neighbouring report, producing the expected failure with the first expression no-oping. Plant with one substitution, so a no-op leaves the log unchanged and the probe fails loudly. And retiring a pinned count leaves the enumeration it fed unfloored — `find` over an empty directory exits 0, the loop never runs, and the pass line reports success over nothing. M30 adds a tenth and an eleventh: searching a REGION for the thing sought, where the region's own furniture supplies it — every character of an index's punctuation is already in the index region, so a presence test there passes for characters that print nothing; assert the entry's own extracted cell. And a planted-defect probe that requires only the NAME of what it planted passes for a reader that reports everything missing; require the reader's own count too. M32 adds a twelfth, about GRANULARITY: a plant per READER is not a plant per CLAUSE. Fifteen plants across three readers here left nine clauses never shown red — among them the identity clause a recorded decision rested on, and the marker clause whose absence let the whole battery pass on a document following half the recipe. Enumerate the reader's clauses and plant each one, or "a planted defect for each reader" certifies discrimination the suite never demonstrated. M35 adds a thirteenth: a plant that does not build the input class its clause is about. The "no rejection at all" plant deleted the stop signature and left the TeX error standing, so the criterion's own input class was never built by any check — the plant was green, its label overstated it, and only a hand-run on a truly rejection-free log showed the clause worked. State what the plant leaves behind, and assert the mutation removed it. M42 adds a fourteenth, a fifteenth and a sixteenth. The fourteenth: a plant that substitutes a STRING can match the plant's own arguments — the cases spelling out `SITE_BASE_PATH="..."` to plant it put four more copies of that string in the file the plant reads, and the exactly-one-site guard fired on the plant itself; anchor the rewrite at a position the arguments cannot occupy, here a line at column 0, and assert there is exactly one. The fifteenth: a plant whose defect is the ABSENCE of something is satisfied by the enclosing tree — a bare directory under the work tree stood in for "a checkout with no remote", and `git -C` walked up out of it and read this repository's, so the case passed for a reason that had nothing to do with the clause; build the absent state as its own self-contained artifact and assert it is one. The sixteenth: a plant that reuses an artifact an earlier case mutated is red for whichever clause the reader happens to evaluate first — the PDF-floor case ran against the copy the previous case had removed a page from, so reordering the reader's clauses, a change with no other visible effect, would have moved it onto the wrong one; give each case its own copy and prove the copy passes unplanted. M48 adds a seventeenth: a source scan whose pattern encodes an incidental FORMATTING choice of what it scans under-matches silently — a regex requiring the shell line continuation between an `indexdump.py` invocation and its redirect could not see the same command written on one line, so a fixture added that way was invisible and the check reported agreement over a set missing it. Plant the sought construct in another legal shape, not only its absence. M54 adds an eighteenth, about what a sweep CANNOT see: a check asserting that every pointer present in a file resolves is blind to a pointer that was removed — rewriting a candidate row dropped one label of the set the old row named, and the sweep stayed green because the token it would have complained about was gone. Where an edit rewrites a set, hold the new set against the old one, not only against the destination.
- 2026-08-17 (M04): A test runner that pipes its check body to `tee` runs that body in a subshell inheriting `errexit` as it stands at the pipeline — a `set +e` before the pipe (to read PIPESTATUS) makes every exit-status-only check advisory while the run still prints "all passed". M22 adds the one-liner shape: `[ cond ] && fail "…"` makes the PASSING case the script's own non-zero exit, aborting the run with no FAIL line.
- 2026-08-17 (M05, consolidated M21 from M15): A later step destroys the artifact an earlier one left, and the check that reads it goes vacuous rather than failing. `quarto render --to pdf` on a book replaces the whole output directory, so an HTML and a PDF artifact of one book never coexist; on a single document it removes the intermediate `examples/<name>.tex`, and a sweep that "skips" that file by basename then sweeps nothing. Copy what a check needs into `$WORK` at the render that produces it and read the copy. M21 adds two more destroyers: a hardening step that deliberately corrupts a record and re-renders one chapter, so the book HTML left at the end of a run is not the state a criterion is about; and the suite itself, which begins by removing `tests/.work`, so two concurrent runs destroy each other mid-flight and the second failure reads as a missing-file defect in the branch. M24 makes the prescription enforced rather than remembered — every render captures, every check reads the copy, and a scan over the suite's own source fails on a working-tree read — but only where the fixture directory is spelled literally: a read reaching it through a shell variable passed that scan unseen, and eleven did.
- 2026-08-18 (M06): A planted test fixture encoding a filter constant — a store version, a chapter count — silently stops testing its rule when that constant changes: the record is then rejected on version, or the count means something other than "per chapter", and the check still passes. Read the constant from the artifact.
- 2026-08-18 (M06): A manifest's derivation comment is its oracle, so extending the manifest without rewriting the comment leaves the new rows unbacked — and a manifest that borrows another's row order cannot be the independent evidence a check comparing the two claims it is.
- 2026-08-18 (M07): A check that reads an element's TEXT cannot tell which element carries it — a div and a heading render the same label, and only one enters the TOC and the id namespace — so assert the tag, class list and id, not the content alone.
- 2026-08-18 (M08): A warning check that counts occurrences passes while the warning names the wrong element. Three rounds of container-report defects all counted right; assert the identity or kind the message is about, not how many fired.
- 2026-08-18 (M10): A criterion inherited from template boilerplate can promise away a defect the milestone's own Scope excludes — "the verify slot passes on a clean checkout" was false before the milestone began and stayed false after it, and two criteria-audit rounds passed it because the audit read the promise and never ran it. M19 adds a second way an audit certifies bad wording: a value's depth is three numbers, not two — what the author wrote, what survives the empty-level drop, and what the ceiling prints — and the number a report held was the middle one while reading as though it named either end, which a two-term vocabulary had no name for and so passed. M26 adds a third: a criterion naming a render that cannot produce the artifact it then compares — "rendered to PDF" against "a captured `.tex`", where this repo's own suite records that `--to pdf` leaves no `.tex` behind — passed a full audit at plan time and another at the amendment gate, and cost a review return. Enumerate every number a value has before a message names one, and read a criterion's named procedure against what the repo can actually run.
- 2026-08-18 (M10): A check that names the entries it inspects by the text they print goes vacuous under exactly the regression it guards — an entry that kept a cross-reference prints the target too, so it no longer matches the name and the clause passes by not matching. Quantify over every entry and name the exceptions instead.
- 2026-08-18 (M11): When one list is realigned against another, a fact about what the AUTHOR wrote must stay measured in the written list. Reading "the last level a key was declared for" off the realigned list turned positional filler into a declaration — and only for entries that needed no realignment at all, so every fixture built from the shapes the change was about passed.
- 2026-08-18 (M11): A fixture built only from the shapes a milestone changes cannot catch a regression in the shapes it leaves alone. Every M11 entry had an empty level, so a defect reachable only WITHOUT one was invisible to thirteen new checks and to the revert probe. Put the untouched shape in the fixture and assert what must not change. M18 adds the mirror, on a milestone whose own subject was two reports contradicting each other: a new report placed ABOVE the branch that drops a value fires for values that were dropped, and every fixture sat at the one depth where the new report cannot fire, so fourteen new checks and a three-lens review of the criteria never reached it. Ask which branch a new report belongs on, and build one fixture at the depth where it must stay silent.
- 2026-08-19 (M12): A hand-derived count over a fixture was wrong on two successive passes here (15, then 17, where the render says 20). Where a check asserts a count the author derived by eye, make the comment show its arithmetic — the sum is what a reader can check. M17 adds the inverse: a pattern-based rename over source lands in PROSE — qualifying every use of a moved definition rewrote the English word in "the outcome they describe differs", because `describe` is also a function name. Bound such a pass with a command rather than by eye: strip the added prefix from every comment line and require the multiset to equal the base's. M24 shows what an unbounded pass costs: rewriting 238 read sites falsified six comments, one by inverting the very rationale of the helper the milestone added, and they surfaced across three review rounds — three of them only after the first repair had looked complete. M27 adds which bound: where the pass rewraps and rewords prose, a substring bound reports reflow as loss and cannot tell the two apart, while requiring every word of four or more characters in each removed line to appear in a destination separates them — it found four real losses in a 37-row move, including a summarized row that had dropped seventeen accumulator names.
- 2026-08-19 (M13): A pinned count of a filter's warning literals cannot see a message split across `..` — the literal count and the call count both stay the same. Only joining every literal in the call's message expression reads what such a scan claims to compare.
- 2026-08-19 (M14): `find … -print0 | xargs -0 grep -l` kills a `set -euo pipefail` suite with no FAIL line at all when any batch matches nothing — grep exits 1, xargs 123, and the run simply stops mid-check. Use one recursive `grep -rl --include=` with its no-match exit absorbed, and let the comparison that follows fail on the empty result.
- 2026-08-22 (M20): An oracle that derives its expectation from the artifact under test is blind in exactly the dimension it derives. Hand-written expected strings here were byte-identical under the defect that broke the feature past page nine, so they certified it; replacing them with a derivation from the same render's `.ind` and `.aux` then hid a wrong-page registration, because expectation and artifact moved together. A derived oracle still needs one fact stated independently of the artifact — here, which page each mark actually sits on.
- 2026-08-24 (M35): A guard only guards where it RUNS. The recipe font guard was correct and its four plants green, but it sat after the renders it protects, so the one input class it exists for died at the render with a message about the recipe and the guard never executed — a check whose own self-test passes can still be silent on the run it was written for. Place a guard ahead of the first thing that depends on it, and verify by planting the defect and reading where the RUN dies, not whether the guard goes red when called directly.
- 2026-08-24 (M28): A grep key holding a RENDERED value cannot be held to a scan that reads source literals — the key's numbers are `%d` there, so the scan reports it matching zero warnings. Give such a scan the key's value-free stem and tie the stem to the key at their shared definition, or the scan silently holds a message the run no longer greps by.
- 2026-08-26 (M40): A documentation section bounded by a bare heading regex ends at the first heading INSIDE a fenced block — a `# References` line in a copyable yaml/markdown sample cut the section holding it, and the check that read that section then swept a domain missing everything below the fence. Bound a section by walking lines and tracking the ``` fence state, never by a lone `^#{1,3} ` match.
- 2026-08-28 (M55): A fixture that holds an axis CONSTANT cannot fail on a defect that needs the axis to vary. Every marker in `examples/book/` sits in one chapter, so no check could reach the first-render placement bug that appears only when a book's markers sit in different chapters — and two criteria scoped to that fixture passed over it. Where a milestone makes behavior depend on an axis, a fixture varies it.
- 2026-09-04 (M074): Moving where a report is DRAWN disarms any plant whose only discriminator was that report's count — M069's whole-gate plant read the four reports a chapter drew for nothing, and once the report site suppressed them it passed either way. Re-check a moved report's plants.
