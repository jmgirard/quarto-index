# M40: The documentation moves into a Quarto website

**Status:** done (2026-08-26, PR #40 https://github.com/jmgirard/quarto-index/pull/40)

**Goal:** A `site/` Quarto website becomes the documentation's home, README shrinks to a pointer, and every claim the acceptance suite pins moves with the prose.

**Outcome:** `site/` is a Quarto website project — `_quarto.yml` (navbar plus docked sidebar, `output-dir: _site`, no `output-file:` overrides, so a source path determines its output path), a `site/_extensions` symlink, and 20 tracked pages carrying README's 17 `##`/`###` sections with their prose intact, one page per topic. README is 57 lines: pitch, `## Install`, the pre-release warning, a link to `site/index.qmd`, and short Examples and Tests pointers. `CLAIM_CONTAINERS` in `tests/run-tests.sh` is the one enumeration of the suite's pinned-sentence sets — 17 rows, 14 presence and 3 absence, each presence row naming the site page or pages holding it and each absence row `ALL` (every tracked page under `site/` plus README); `claim_text` builds each check's comparison text from that row, and `check_claim_registry` compares the registry against a scan of the suite's own source in both definition shapes. Three section-anchored checks take their heading as a parameter and bound the section outside fenced blocks, which a bare regex got wrong on a `# References` line inside a copyable block. New `tests/sitecheck.py` carries five modes — `rendered`, `links`, `headings`, `readme`, `prose` — each reporting its swept domain's size; `capture` gained a `--site` mode. `rendered`, `links` and `readme` run standing; `headings` and `prose` state a one-time fact about the migration and run against the merge base. 27 planted cases, one per clause, plus a positive control.

**Decisions:** D-023 (annotates D-016, D-018) — the engine-and-font recipe's home is the docs site's Terms outside Latin-1 page, and IP2's non-ASCII condition names it there. Chosen at an amendment gate with escalation offered and declined. AC6 was replaced at a gated amendment: as planned it was unsatisfiable, since six presence containers span two or more pages.

**Review:** Three-lens fan-out (user-facing tier, executable surface). All eight criteria met with fresh evidence — a clean-clone render (20 pages, exit 0), 752 same-site links resolving under a resolver written at review and confined to the capture, 942 dropped-line words all reaching a site page, 17 headings moved, README at 57 lines, 168 presence entries landing and 16 absence entries absent from all 24 files, and `--self-test` green at 595 checks. Consistency gate clean. 23 findings. Fixed on the branch at the gate: five `above`/`below` cross-references made false by the move, now links; six comments still locating the recipe in README after D-023 moved it. Rejected with reason: reading a claim container's "entry" as the whole row rather than the pinned sentence. Nineteen absorbed into the standing acceptance-suite hardening candidate row — an absence row's `ALL` domain that nothing pins, a tag field no check reads, a completeness scan whose name pattern predates the move, three presence rows whose registered domain no code reads, link resolution not confined to the published site, and clauses with no planted case. No defect return.
