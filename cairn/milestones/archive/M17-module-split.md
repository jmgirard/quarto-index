# M17: index.lua becomes a thin entry point over required modules

**Status:** done (2026-08-20, PR #17 https://github.com/jmgirard/quarto-index/pull/17)

**Goal:** `_extensions/index/index.lua` becomes an entry point that requires modules under `_extensions/index/modules/`, with the acceptance suite unchanged.

**Outcome:** The 2,729-line filter became a 256-line `index.lua` — mark-syntax header, seven requires, `Pandoc`, the pass list — over nine modules: `core.lua` (constants, `warn`, the format tests), `levels.lua`, `sortkeys.lua`, `latex.lua`, `marks.lua`, `passes.lua`, `html.lua`, `marker.lua`, `book.lua`. Loaded with a relative `require("./modules/<name>")`, which Quarto has patched since 1.4. The seven shared accumulators plus `xref_list_emitted`, `xref_both_emitted` and `marks_seen` moved into the module that owns each — tables shared by reference, scalars as `M["name"]` fields. `tests/movedefs.py` now relocates definitions from the whole source set rather than `index.lua`, and `tests/run-tests.sh` gained an install-path probe: 30 requires all top-level above their file's first definition, plus a standalone fixture and a book project rendered to latex and html from a `quarto add` install and from the working tree, byte-identical. 195 -> 197 checks, 230 -> 232 under `--self-test`. DESIGN.md's Architecture section names every module; its Conventions gained the bracket-export/definition-form rule and the `qi_<name>` alias rule.

**Decisions:** three milestone-local, all forced by merge-base checks: imported names are reached through the module table and never re-bound as same-named locals; a module exports through `M["NAME"] = NAME`, since a plain `M.NAME = NAME` masks its own definition once the moved-definition probe relocates it (M16 review F3); a module is required under `qi_<name>`, since `levels`, `marks` and `marker` are ordinary local names here. None cross-cutting.

**Review:** two passes, three fresh-context lenses each, 27 findings. Pass 1 returned the milestone on AC2 — the probe's `ok` lines shifted the self-test's by two, and the tick was withdrawn rather than the criterion reread; the probe now runs last. Seven fixed then, three to candidate rows (no suite check guards AC1's rule; 14 -> 62 over-80 lines; whole-surface exports), three refuted or rejected. Pass 2 confirmed AC2 holds under either reading of "position" and that the relocation changed nothing any check asserts; twelve more findings, ten fixed, two moot, one logged. The [O] lens reconstructed the byte-diff oracle D-004 deleted — 29 fixtures x 3 formats plus all 6 book renders, at both revisions — and found every output, render log and exit code identical, evidencing the residual risk the Scope had accepted. Nothing retired at hygiene; the standing discriminating-checks lesson took a fifth shape.
