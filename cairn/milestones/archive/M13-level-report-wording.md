# M13: Level reports name a depth the author can act on

**Status:** done (2026-08-19, PR #13 https://github.com/jmgirard/quarto-index/pull/13)

**Goal:** The two reports about a mark's levels say something the author can act on: an empty level is reported once per mark naming which written positions were empty, and the extra-sort-levels report stops reading as a claim about the depth the entry indexes at.

**Outcome:** `drop_empty_levels` emits one report per mark rather than one per dropped level, naming the empty positions in the value as written and how many of those written levels remain — never the indexed depth, which the shared layer cannot state format-neutrally because the LaTeX three-level fold runs later. `sort_levels`' report labels both counts as taken before the drop and holds for a mark carrying `sort=` with no `entry=`, which reaches it through the visible-text fallback. `examples/empty-levels.qmd` gained the three-way depth shape (`entry="Moles!" sort="a!b!c"`: written 2, sorted 3, indexed 1) and its no-`entry=` twin. The M02 warning-distinctness scan was rewritten to join every literal in a call's message expression rather than read the first, to strip Lua block comments, and to find `:format(` only outside message text.
