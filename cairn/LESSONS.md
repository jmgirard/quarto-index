- 2026-08-16 (M01): Inside `\index{}` LaTeX reads under `\@sanitize` (`\` becomes catcode 12, so `\{` escapes nothing), and hyperref rewrites the argument at its first `|` before makeindex runs. Neither is discoverable from the character alone. Extended M114: a contents line drops `\index` with `\@gobble@som`, not `\@gobble`, so compare `\index` with its document meaning.
- 2026-08-16 (M02): makeindex parses `!` and `@` inside the encap argument too, so a cross-reference target needs the same quoting an entry key does — braces do not shield it. An unquoted `!` there is rejected outright, which under Quarto means a failed build rather than a lost entry.
- 2026-08-17 (M04): imakeidx's `\printindex` closes the `.idx` file it has just read, so an index printed mid-document silently drops every later `\index` — the entries go to the `.log` and the build stays clean. Its `noautomatic` option skips that close.
- 2026-08-17 (M04): Quarto emits `use_latex_package` as `\@ifpackageloaded{pkg}{}{\usepackage[opts]{pkg}}`, so options never reach a document that loads the package itself; and `\PassOptionsToPackage` registers options on an already-loaded package, which defeats an `\@ifpackagewith` check written to detect exactly that case.
- 2026-08-17 (M05): `pandoc.system.make_directory` raises a Lua error rather than returning a failure, so an unguarded call aborts the whole render; the `io.open` beside it returns nil and err, which is why one of the two was guarded and the other was not.
- 2026-08-18 (M08; corrected M12): `doc:walk` traverses `meta` as well as `blocks`, so a document-wide walk reports marks in the title or abstract. `Block:walk` visits an element's contents, never the element, so check a top-level container directly. On Pandoc 3.10.2 a `Block` walk reaches a footnote's blocks, so an extra `Note` handler double-counts. A traversal fact in a code comment holds for one Pandoc version: re-probe it.
- 2026-08-18 (M09): makeindex keys an entry on its sort field, so `X@X` and a bare `X` are one key — comparing emitted `\index` argument strings to find a collision splits pairs the tool merges, and comparing what each level actually files under is what reads the tool's own view.
- 2026-08-18 (M09): A report that quotes a value the code derived — a fallback filled in where the author wrote nothing — hands them a string they never typed and cannot search for; name the fallback as what it is.
- 2026-08-18 (M10, M11): makeindex reads `!` before an encap as part of the encap, not as a level separator — `\index{Cats!|see{X}}` is accepted and prints `Cats`, where a bare `\index{!Cats}` is rejected outright. A null-field rule inferred from one of the two does not transfer to the other. From M10: a trailing null field is swallowed (`\index{Moles!}` prints the bare top-level term), so the two empty-level shapes fail in opposite ways.
- 2026-08-18 (M11): makeindex falls back to the SORT key when a level's printed half is empty, so `\index{mmm@!Cats}` silently prints `mmm` as a parent term the author never wrote — accepted, exit 0, no warning. An entry surviving the tool is not evidence it survived intact.
- 2026-08-19 (M13; extended M56): The sort-key registry keys on an entry's printed level path, so a new fixture mark whose path matches another probe's silently takes that probe's key. Give a new mark a term no other mark in the file indexes. Extended M56: metadata collides the same way. Quarto injects a `labels:` map into every document, so before claiming a top-level key, render a fixture declaring none and read the metadata, and namespace the key (`index-labels:`). Extended M57: Quarto's YAML schema rejects a non-string `lang:` before the filter runs. Render the bad value first: what the host rejects is not yours to guard.
- 2026-08-19 (M14): A per-record field that only a warning reads is not a format change. Bumping the store version for it invalidates every OTHER chapter's record, so a single-chapter re-render drops their terms from the book index — a real loss traded for wording. Make such a field optional with a named fallback and leave the version alone.
- 2026-08-22 (M21): A per-chapter record that mixes what the author WROTE with what that chapter CONCLUDED is read in another process as though every field were raw. Three review rounds each found one defect from that conflation, each repaired where found and left standing on its sibling field. Where a record crosses a process boundary, give the author's values and a reader's conclusions separate names.
- 2026-08-22 (M22): A LaTeX auxiliary file outlives the source that wrote it (`latex-clean: false`, or a failed render), so every command the filter writes into one is an input to the NEXT render — a render whose marks no longer define it. The `.aux` is read at `\begin{document}`, so a stand-in only acts from the preamble whether or not an index is printed; the `.ind` is read later, at `\printindex`, so only a document that prints an index can ever read a stale one (corrected M31, which covered the `.ind` too).
- 2026-08-24 (M05, M29): A PDF book is ONE Pandoc process over the concatenated chapters, where an HTML book is one per chapter — so a position or ordinal a chapter's own render reports is a different number in the PDF render of the same book (blocks 8 and 5 against 26 and 34 here). An expectation written as "unchanged across the two formats" is unsatisfiable; only the parts that genuinely cannot move may be pinned. From M05: an HTML book's chapters render in book order, `doc.meta.book.render` carries the ordered chapter list and `quarto.project.offset` the page-to-root path, so cross-chapter work needs only somewhere to leave data between processes.
- 2026-08-24 (M30; extended M33, M100, corrected M108): A PDF's text layer does not hand back what the source carried. In a T1 font `'` and `` ` `` extract as curly quotes and a `,` entry beside the delimiter comma extracts as `„`; Typst on Quarto 1.5.52 maps `fi` to `ﬁ` and `!!` to `‼`, which the Typst reader folds in NFKC and `typstindex.py pages` does not. Extraction also renormalizes Unicode both ways. Compare in NFC, and fill an expected-extraction table from the typesetting fact behind each row, in precomposed form, never from what the artifact under test returned.
- 2026-08-24 (M31): TinyTeX ships RESTRICTED shell escape, whose whitelist includes makeindex, so imakeidx rebuilds the `.ind` mid-compile before `\printindex` reads it. A stale-index hazard passes silently here and stays live wherever shell escape is off. `-no-shell-escape` holds the file stale; assert it byte-identical after the run to prove the probe read the stale one.
- 2026-08-24 (M31): A stand-in for a command that PRINTS one of its arguments must pass that argument through, not gobble it. A gobbling stand-in for a locator command turns a stale index into one with no page numbers in it: a render that builds and lies, where the point of a stand-in is a render that builds and tells the truth.
- 2026-08-24 (M33; corrected M34): Quarto's default PDF engine is not pdflatex — on 1.10 it is lualatex — so the loud pdflatex stop is a signature an author reaches only by opting into pdflatex, and a document that sets a non-Latin-1 `mainfont` and leaves `pdf-engine:` alone gets whatever that default gives it. What that is depends on the font, not the engine: under `stix` the render exited 0 and corrupted `Việt`, under STIX Two Text it exits 0 and prints every term. Read the printed index, never the exit code. Nor the log: xelatex prints a precomposed character its font lacks through its canonical decomposition, so `Missing character` fires on text that typesets perfectly.
- 2026-08-25 (M36): TeX ends a failed run with `!  ==> Fatal error occurred, no output PDF file produced!`, a whole error report on ONE line that no `l.<n>` echo closes; in the pdflatex control's log it also closes the inputenc report above it. A log reader that needs an explicit close depends on how the log ends, and one that closes an open report at end of file absorbs the chatter after it. Pick which way to be wrong and say so where the reader is defined.
- 2026-08-25 (M36): Python's `str.isdigit()` is true of digits in EVERY script and `int()` reads them, so a guard written as `level.isdigit()` takes `'٣'` as level 3 — a value no caller writing the suite's own specs by hand can have meant. A guard over a hand-written domain names the spelling it accepts (`isascii() and isdigit()`), never the language predicate that happens to sit near it.
- 2026-08-25 (M37): bash suspends errexit inside a subshell in an `&&`/`||` list even when the subshell sets `set -e` itself, so `( set -eo pipefail; f ) && rc=0 || rc=$?` runs `f` shielded and is green on the defect it tests for. Background the subshell and read its status with `wait`: only `wait` sits in the `&&` list, and the call runs unshielded.
- 2026-08-25 (M37): under `set -u`, bash 3.2 (macOS, what this repo runs) errors on `"${A[@]}"` for an empty declared array, where bash 4.4 and later expand it to nothing. An argument resting on that behavior holds on one shell only, so argue it from something the check pins, such as self-test plants that each name one of the listed lines and could not go red over an empty list.
- 2026-08-25 (M38; extended M073, M080, M081): When a judgement's scope narrows, the message reporting it goes false in silence — and a grep key chosen for stability hides exactly that. Keying the dangling-target check on the invariant tail (`indexes; a reader following...`) meant the clause that went wrong, "in this document", was the one clause no check read; three rounds of green suites shipped a report telling authors to mark a term they had already marked. When a change narrows what a check or a rule is computed over, re-read every message that names that set, and pin the varying clause somewhere, not only the stable one. Extended M073: comments enumerating that set are messages too — a closed three-item list of record states, in three files, went false when a change added a fourth. Extended M080, M081: fixing one false count or enumeration on a page leaves its others standing, so re-read them all.
- 2026-08-26 (M39): `tests/scans/m15-joined-messages.py` balances parentheses from every `warn(` in raw Lua source, comments included, so a comment holding a bare `warn(` swallows the rest of the file and the next file's messages. Only `--self-test` caught it, because its moved tree reorders the files. In prose about the call, write `warn()`.
- 2026-08-26 (M41; extended M44, M45, M52): A residue sweep that greps a page's markup for a plumbing string goes false once a page prints that string as content (the gallery shows a fixture's source). Ask the parsed page whether an element carries the attribute. Flattening whitespace misses markup inside prose: a blockquote's `>` lands mid-sentence, so strip the wrapper per line first. Extended M45: give each failing shape its own message, most specific first, and plant a page with two shapes. Extended M52: a second module re-implementing the sweep does not inherit the fix, and a re-wrapped plant discriminates only when the break falls inside the phrase. Break the input where the normalization acts, and show the pre-fix comparison missing the plant before trusting it.
- 2026-08-26 (M42): GitHub Actions fields do not mean what their names suggest. `github.ref_name` is the tag name on a tag push, so gate a deploy on `github.ref` against `refs/heads/<name>`. A job-level `permissions:` replaces the workflow-level one, so restate every scope the job needs. A workflow-level `concurrency:` group serializes every branch; put it on the deploy job. `quarto install tinytex` calls the GitHub API unauthenticated and gets 403 when runs start together; pass the run's token. A bare `on: push` also matches tag pushes; keep a probe commit under a ref outside `refs/heads` and `refs/tags` (`refs/probes/*`).
- 2026-08-26 (M43): An old Quarto's toolchain is not today's in miniature. Quarto 1.4.549's TeX installer fails on `imakeidx.sty` against today's TeX Live, so install the fixtures' packages with the runner's TinyTeX on every leg. `tlmgr` is not on PATH, refuses to install before `update --self`, and `mirror.ctan.org` can hand two jobs different mirrors, so name the repository. Extended M51: under `set -o pipefail`, `$(find ... | head -1)` fails the step before its `-z` check prints; use `| head -1 || true` and let the named check fail. A step restored verbatim from its deleting commit is stale against what the fixtures did since.
- 2026-08-26 (M43): A GitHub Actions job that reports over partial results needs `if: always()`, since `needs:` gates on success. Extended M106: steps gate the same way, so a reading that must report past an earlier red reading needs `if: ${{ !cancelled() && steps.<render>.outcome == 'success' }}`; only a probe expecting it red shows it skipped. Under `set -e` a step capturing a reader's stdout swallows its failure message: write diagnostics to stderr. Extended M45: print a reader's domain-size line before the verdict, not only on the all-pass path, and assert it on a planted red run.
- 2026-09-03 (M073): bash reads a script lazily by byte offset, so editing `tests/run-tests.sh` while a run is in flight corrupts that run's parse: a leg failed, then the shell reported a syntax error at a line the file no longer had. Batch edits until the run ends, a long wait included.
- 2026-09-06 (M079; trimmed M080): A fixture writing each case in a unit of its own cannot see a defect about cases interacting within that unit.
- 2026-09-07 (M082): `tests/htmlindex.py` subclasses `HTMLParser`, whose internals move between Python versions (3.12 gives `set_cdata_mode` a keyword-only `escapable=`), while the suite's local interpreter is 3.9 and CI's 3.12, so a suite green here can raise a TypeError there. Take an override's signature with `**kwargs`, and run the reader's probes under the oldest and newest interpreters in reach. Corrected M117: `/usr/local/bin/python3` (3.14.6, no PyYAML) now comes first on PATH and stops the suite at its PyYAML check, so run it with `PATH=/usr/bin:$PATH`, which gives 3.9.
- 2026-10-19 (M115): An edit a filter makes to a Quarto float's content changes what Quarto does with it later. A wrapper merged layout cells, a label joined to an image cell kept a width Quarto drops, and a wrapper around a code cell's output Div stopped its unwrap. The index read right each time, so check the layout against an unmarked twin of the float.
- 2026-10-20 (M116): A new fixture is registered in more places than its own suite section. Every `.qmd` under `examples/` that writes `see=` or `see-also=` needs a row in M14's dangling-count corpus, which greps the files one by one, so a shared include body holding the marks reads as a fixture of its own; and every top-level `examples/*.qmd` needs a line in `site/gallery.yml`. Each new `warn()` literal moves `warn-distinct.py`'s pinned count. Write twins out in full and hold them equal with `derive_labels_twin`.
- 2026-10-20 (M117): A change to what a back-end prints for a degenerate shape moves other milestones' plants, whose want strings quote the old output: the M099 dropranges and M098 alt-kept plants each read a row with no locator that M117 removed, and each cost a whole suite run to find. Before the first run, grep the self-tests for want strings resting on the old behavior. Also: pdftotext opens each page after the first with a form feed, so an exact-line match on a heading there needs `\f` turned into a newline first.
