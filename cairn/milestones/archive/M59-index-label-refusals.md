# M059: The words an author writes are refused when a reader cannot read them

**Status:** done (2026-08-29, PR #59 https://github.com/jmgirard/quarto-index/pull/59)

**Goal:** Every unusable `index-labels:` value an author can write is reported and falls back, which is what the surface already promises and four shapes do not do.

**Outcome:** `read_labels` in `indexes.lua` refuses a value holding no character outside `BLANKS` — 27 entries written at one site, spelled with `\u{}` escapes so the source stays ASCII — and one whose Pandoc type is a map or a list, naming the shape the author wrote; the empty-value report is reworded from "an empty value" to "a value with no character a reader can see" so one report covers both, moving three needles with it. A new `report_dropped_labels` is called from all four `read_declaration` refusal branches an entry carrying an `index-labels:` key can reach — no `name:`, an empty one, a name that is no section id, a repeated name — and says that key sets no word without reading it. `grouped_blocks` in `html.lua` collects the headings it prints and reports, once per index per render and so never on a format with no letter groups, where the non-letter group's heading is character-for-character one of the same index's letter headings; what prints is unchanged. `examples/index-labels-misuse.qmd` grows a fourth declared index and four entries refused as declarations, its whole-render report total pinned at 18 against a per-writing-site derivation; `examples/index-labels-clash.qmd` is new, carrying a clashing word and a silent one. Six planted defects under `--self-test`, `warn-distinct` pinned 74 → 77, and KI173-KI176 closed.

**Decisions:** Milestone-local: the blank list is written out rather than derived from a character property, since the Lua Pandoc embeds ships no Unicode category tables and `%s` follows the C locale; the refusal covers all five writable keys, the two punctuation ones included, which takes away the only way to ask for no word at all and opens a candidate row for it; and the letter clash is compared character for character, so `symbols: "a"` draws nothing in an index with an `A` group.

**Review:** Three-lens fan-out; blame-history and prior-review found nothing, diff-bug nine, none meeting the return floor. Fixed at the gate: a refused entry's further message asserting an `index-labels:` map without ever looking at the value's shape; a fallback ladder this branch added to the changelog and both documentation pages running the two punctuation marks through `lang:`, which no language row holds and which the M58 changelog entry already said; a stale count of six in a live self-test comment the fixture growth made eighteen; and `read_declaration`'s docblock left above the newly inserted function. Rejected: the clash report naming "this document" below two indexes, which is `scope_phrase`'s established convention on an unmodified line. Deferred as KI194-KI197 behind the existing label-surface check row, extended to name M59.
