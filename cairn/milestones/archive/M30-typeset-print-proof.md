# M30: A character in an index entry is proved to print, not merely to compile

**Status:** done (2026-08-24, PR #30 https://github.com/jmgirard/quarto-index/pull/30)

**Goal:** Every printable ASCII character `examples/escaping.qmd` indexes is proved to reach the compiled PDF's index as its own entry, not merely to compile and be accepted by makeindex.

**Outcome:** The escaping probe's typeset assertion is now `esc_typeset_check` in `tests/run-tests.sh` — one shell function, called at the acceptance site and again by the self-test, so no second copy can drift (the shape M15 sent to the hardening row as two independent joined-`warn()` readers). It reads the captured PDF through `pdftotext -layout`, splits the index region on runs of two or more spaces into cells (a printed index is two columns on one extracted line), and sweeps `range(0x21, 0x7F)` — the domain by construction, no skip list — requiring each character's own entry cell rather than its presence anywhere in the region, which the index's own punctuation would satisfy. The named `EXPECTED_CELL` table carries the three characters whose cell is not `<char>, <page>`, each row stating a typesetting fact rather than a value read back from the artifact under test: `'` and `` ` `` extract as the right and left single quotation marks, which is what a T1 text font holds at those ASCII positions, and `,` extracts as `„<page>` because makeindex writes `\item ,, \hyperpage{N}` and `,,` is that font's ligature for the double low-9 quote, merging the entry with the index style's delimiter. A guard fails the check when the region yields no cells, so a reader that found nothing cannot report nothing missing. A permanent `--self-test` entry renders a copy of the fixture with the apostrophe's two marks removed (one substitution each, asserted) and requires the same reader red, naming `U+0027` and reporting `1 of 94`. 431 checks under `--self-test`. KI86 struck; KI87 filed for the comma ligature and the two quote positions.
