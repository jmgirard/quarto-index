# M26: A document's accumulators start empty, whoever ran before it

**Status:** done (2026-08-23, PR #26 https://github.com/jmgirard/quarto-index/pull/26)

**Goal:** Every module-level accumulator the filter's passes share is returned to its initial value at the start of each document, and a render proves it.

**Outcome:** The 17 mutable module-level cells — `marks.lua`'s ten, `latex.lua`'s six, `sortkeys.lua`'s `sort_keys` — are restored per document by a `reset` each of those three modules owns, called from `passes.Reset`, which `index.lua` returns as the pass list's leading `{ Pandoc = ... }` table: no element function, so Pandoc runs it as one traversal before any `Span` pass. Tables are emptied in place through a new `qi_core.empty`, since every accumulator is exported by reference and a rebound local would restore only its own module's view; `principal_ordinals` and `range_at` are pure locals restored by assignment, `marks_seen` a field on `M` because a scalar cannot be shared by reference. The oracle is three new fixtures — `examples/state-reuse.qmd` reaching the fourteen value-carrying cells, `-plain` with one mark, `-empty` with none — each rendered twice off one tree with `tests/state-pollute.lua` in its filter list, which drives a synthetic colliding document through the pass list when `QI_STATE_POLLUTE` is set and silences the extension's `warn` for that drive. Twelve new suite checks `cmp -s` each pair's captured artifact and captured warning stream across latex and html; `tests/stateprobe.py` runs 21 planted-defect probes. 397 -> 409 checks under `--self-test`. DESIGN.md's Architecture paragraph records the per-document reset and the convention that a new accumulator joins its module's `reset` in the commit that adds it.

**Decisions:** one milestone-local — the per-cell probe verdicts, naming for each of the 17 cells the fixture, format and artifact that its removal from the reset moves, and recording `range_pair_found` as the one exempt cell, since `finish_ranges` assigns it wholesale on every document. D-012 was written at plan time and stands in DECISIONS.md: a same-tree pollution comparison is not the refactor oracle D-004 refused.

**Review:** two rounds, three lenses each, both run in-session rather than in spawned readers (each session was instructed not to spawn agents) — the weakest arrangement on record here, and round 2's reviewer had authored the amendment it was reviewing. Round 1 returned the milestone on AC1: the criterion asked for a PDF render but compared a captured `.tex`, which no single render here produces, and named a second render without the pollution filter where the implement gate had chosen one source and an environment switch. Amended through the gate, then all five criteria verified in round 2 on fresh runs. Six further findings, none actioned: AC2's "emitted preamble" clause binds nothing on a back-end that emits none by design (GP4), and the whole-page comparison is wider than it asks; `reset` is the first name with three top-level definitions in the source set, which `movedefs.py` fails loudly on and is not asked to move; and four checks came back clear — the 17-cell enumeration still exhaustive, each cell's reset form matching its reach, the reset not cutting a book's index, M17's export conventions upheld. Nothing retired at hygiene; M10's criteria-audit lesson took a third shape.
