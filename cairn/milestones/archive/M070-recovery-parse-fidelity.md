# M070: A recovered chapter is read as the file it is, and everywhere its own render reads it

**Status:** done (2026-09-02, PR #70 https://github.com/jmgirard/quarto-index/pull/70)

**Goal:** The recovery parse is given only a chapter source Pandoc's markdown reader is the right reader for, and reads a mark wherever that chapter's own render reads one, so a recovered chapter's terms are neither refiled into the wrong index nor left out of every index, silently either way.

**Outcome:** `readable_source` in `_extensions/index/modules/book.lua` tests a chapter path's own extension, lower-cased, against the enumerated `SOURCE_EXTENSIONS` set — `.qmd`, `.md`, `.markdown`, `.Rmd`, a name carrying no extension refused with the rest — ahead of `recover_record`'s `pcall`, so nothing is opened; the refusal returns a second value the caller tells from a failed read, and such a chapter draws a fifth store wording naming the file and the accepted set, drawn once per reading chapter ahead of the other four, asserting nothing about the record and so exempt from D-045's silence rule. Before this a book's `.ipynb` chapter had its raw JSON parsed as markdown and its terms filed into the book's first index with nothing said (KI219). `recovered_marks` now takes `(meta, blocks)` and walks the metadata and then the blocks — the order an ordinary render sees them in, so a front-matter sort key beats a body one exactly where it beats it there — with `drop_conditional`'s filter reaching the metadata through `conditional_free_meta`, so a front-matter mark carrying or inside `.content-visible`/`.content-hidden` is dropped as a body one is. `recovered_markers` stays over the blocks alone, matching `resolve_markers` (KI11). Suite: new fixture `examples/book-extensions/` of nine chapters in five source kinds, three legs (cold store, listed-unopenable record, and a record-route control rendering `six.qmd` and `eight.Rmd` from their own records), href-form manifests of 25 rows, and seven `--self-test` plants each shown red first — 642 checks plain, 1207 with `--self-test`; `warn-distinct.py` 82 → 83. Prose in `site/books.qmd`, `CHANGELOG.md` and DESIGN's recovery section; the books-page claim ledger 27 → 31 rows.

**Decisions:** D-046, the enumerated extension set and the refusal that reports it, narrowing D-041's "a chapter's own source" to a set the code names; D-047, front-matter marks in what that parse yields, narrowing D-041 and extending D-042's conditional-content removal from the blocks to the metadata.

**Review:** three rounds, three-lens fan-out each. Two defect returns — AC1's "asserted message-whole" clause with nothing asserting the refusal named the file, and an over-general refused-chapter claim on `site/books.qmd` and `CHANGELOG.md` that told a notebook author their terms were lost on the whole-book path where they are not — and one amendment return, AC3 having quantified over every front-matter mark including a `.content-hidden` one that recovery drops by D-042 and the render indexes. Round 3: all five criteria verified, ten findings, none meeting the return floor. Six fixed: KI233's "a field Quarto does not reflect" discriminator corrected after measuring that a reflected `abstract:` mark also files locators whose fragments its page lacks (two of three dead); an `Rscript` preflight for the fixture's `.Rmd` chapters, whose own render Quarto runs through knitr, and `m070_render`'s failure message unpinned from the refusal framing it hard-coded; `books.qmd`'s unqualified "the two agree" narrowed to the entry and the index; `recover_record`'s IP2 comment, the split conditional drop, and the fixture header's chapter count. Four rejected. KI219 retired; KI232-KI234 added; one candidate row carries the deferred pair.
