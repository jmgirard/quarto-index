# M072: A refused chapter whose record an older version wrote is reported once per index section

**Status:** done (2026-09-03, PR #72 https://github.com/jmgirard/quarto-index/pull/72)

**Goal:** In an HTML book, a chapter whose source the recovery route will not read is reported, where its record was written by a different version of this extension, on the count every other different-version report follows — once per chapter that builds an index section, and once by a chapter whose records show no chapter of the book placing an index — rather than once per chapter that reads the store, so a book carrying a notebook chapter with an old record hears about it as often as it hears about any other stale record.

**Outcome:** `store_read` (`_extensions/index/modules/book.lua`) now tests the version-skewed state (`ok and type(data) == "table" and data.version ~= STORE_VERSION`) BEFORE the refusal, and on that branch appends `{ file = file, refused = true }` to `stale` instead of warning inline; `html_book`'s one report site draws the refusal for `entry.refused` first, inside the existing `if builds or first == nil` gate (M55/M062's rule), ahead of and instead of the three different-version wordings. The never-written, listed-unopenable and undecodable states keep the inline draw and their counts. The wording moved into one helper, `warn_source_refused`, called from both sites, so the source set still holds one literal for it and the distinct-message scan's pinned count is unchanged. Suite leg `m072` over `examples/book-extensions`: the store filled by a whole-book render, `five.ipynb`'s record version rewritten and nothing else, the refusal counted from `index.qmd` (builds both sections) and `one.qmd` (builds none) in all four record states, with the pre-plant store as the control; the six other store wordings held at zero and the naming clause read subtractively behind a non-empty-domain fence; two planted defects (the site gate turned round, the refusal test moved back ahead of the version test) shown red. 663 checks plain, 1239 with `--self-test`. `site/books.qmd` (ledger 32 → 33), `CHANGELOG.md`, DESIGN's recovery section; KI234 struck.
