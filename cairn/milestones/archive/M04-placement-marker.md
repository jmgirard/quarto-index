# M04: Index placement marker

**Status:** done (2026-08-17, PR #4 https://github.com/jmgirard/quarto-index/pull/4)

**Goal:** Ship a format-neutral placement marker — an empty div with class `qi-index-here` — that puts the index where the author wrote it, in every back-end, with today's auto-append preserved when no marker is present.

**Outcome:** Marker recognition in index.lua, top-level blocks only: `resolve_markers` warns and strips every marker that cannot be a placement site (below the top level, after the first — named by ordinal and top-level block position), warns on content inside a marker and on an id or extra class written on it, and runs before any back-end branch, so misuse is diagnosed in every format and no marker survives into any output. One `place_index` both back-ends call — HTML index section and LaTeX `\printindex` at the marker, appended when there is none, every marker stripped either way — so placement cannot drift between them. The LaTeX-only `marks_emitted` became the format-neutral `marks_seen`. Marker documents load imakeidx with `noautomatic`: a mid-document `\printindex` otherwise closes the `.idx` file it reads and every mark below the marker goes to the log instead; a document that preloads imakeidx cannot be reached that way, so it gets a begin-document `\@ifpackagewith` warning naming what will be missing. Fixtures: `marker`, `marker-misuse`, `marker-nomarks` (+ a marker-free twin), `marker-preloaded`. Suite: document-order primitives in `tests/htmlindex.py` (`position`, `position_of_id`, `empty_divs`), placement and misuse checks across HTML, LaTeX, PDF (index slice bounded by the following heading), gfm and beamer, structural residue checks plus a byte-identical twin-render pin, a planted-defect probe for the runner itself, a printed check count (72, against 44 at the merge base), and `tests/byte-diff.sh` looping the merge-base LaTeX fixtures (8/8 byte-identical). README gained "Placing the index"; DESIGN records marker resolution and shared placement.

**Decisions:** milestone-local — a non-empty marker keeps its content, printed where the marker was, with a warning (IP2 forbids deleting it); a marker below the top level places nothing and leaves the index in its automatic position rather than suppressing it (GP4); with more than one top-level marker the first wins.
