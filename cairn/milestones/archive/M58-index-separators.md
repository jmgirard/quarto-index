# M058: An author sets the punctuation the index prints inside an entry

**Status:** done (2026-08-29, PR #58 https://github.com/jmgirard/quarto-index/pull/58)

**Goal:** The two punctuation strings the HTML and EPUB index prints inside an entry become author-settable under the existing `index-labels:` map.

**Outcome:** `LABEL_KEYS` in `indexes.lua` gains `separator` and `xref-separator`, which extends the unknown-key report to five keys and puts both under the existing empty-value branch with no new validation. `html.lua`'s `entry_inlines` resolves each once per entry through `qi_indexes.label(name, ...)` and prints them at the five positions an entry reaches: `separator` between a term and its locators, between two locators, and in front of the first cross-reference whether locators precede it or not; `xref-separator` between two cross-references. Each `pandoc.Space()` stays the filter's, so a key sets the glyph alone. Resolution is the words' own ladder — an index's own map, then the document's, key by key — with no language-table row beneath it, so neither key follows `lang:`, and nothing reaches LaTeX, held by a byte-identical `.tex` comparison against a twin. Three fixtures (declared, twin, per-index scoped), a per-index empty-value map added to the misuse fixture, a new `tests/sepcheck.py` deciding HTML and EPUB against hand-derived code-point manifests with a row-count assertion, `entry_separators` added to `tests/htmlindex.py`, and a five-form planted-defect matrix.

**Decisions:** Milestone-local: two keys rather than one per printed position, no convention found distinguishing them; the trailing space kept with the filter rather than written into the value; and no `ar` row shipped in the language table, since one reference alone does not settle an index-specific claim.

**Review:** Three-lens fan-out; blame-history and prior-review found nothing, diff-bug eleven, none meeting the return floor. Fixed at the gate: three docs and changelog claims about where LaTeX's cross-reference semicolon lives, which named the command definition where the shipped fixture reaches `fold_xrefs`'s own join; the same three omitting the term-to-first-cross-reference position `separator` governs; a line count standing in for a command count in AC6; a wrong counterfactual in the AC3 comment; and a candidate row not covering the `TARGET_JOIN` half its Scope Out defers to it. Rejected: a fixture sentence read as self-contradictory, whose "below" is the body. Deferred as KI190-KI193 behind one candidate row.
