# M33: An index term outside Latin-1 prints in the PDF index

**Status:** done (2026-08-24, PR #33 https://github.com/jmgirard/quarto-index/pull/33)

**Goal:** An author indexing terms outside Latin-1 gets them printed in the PDF index by following one documented engine-and-font recipe, and the repo's stated promise about non-ASCII terms says what is true.

**Outcome:** README's `### Terms outside Latin-1` names the recipe — `pdf-engine: xelatex` plus `mainfont: STIX` loaded by file through `mainfontoptions` (the plain family name is not findable), `tlmgr install stix` since it lives in `collection-fontsextra` — and names three failure paths, the `Missing character` caveat, what `sort=` does, and the proven set. `examples/unicode.qmd` marks eight one-level terms (Greek, Greek with `sort=`, Cyrillic, Polish, Vietnamese, a decomposed `café`, `Nux̌alk` with no precomposed form, and an ASCII positive signal). `tests/unicodeprint.py` adds four readings — `marks`, `entries`, `stopped`, `absent` — reading each term's OWN entry line out of the captured PDF, locators removed, compared in NFC. Four control renders, each one YAML edit from the fixture, pin pdflatex's loud stop on U+03B8, the default font's silent Greek drop, the CJK drop under the full recipe, and the no-engine path where the build succeeds and only `Việt` is corrupted. Fifteen self-test plants over fifteen reachable clauses. IP2 now carries the engine-and-font condition; KI6 narrows from "a decision this repo has not made" to the proven set and the unproven remainder. Suite 336 → 487 checks.

**Decisions:** D-016 (IP2's non-ASCII promise is conditional on the document's PDF engine and main font; remedy is the documented recipe, not filter-side detection, which would need to supersede D-003) and D-017 (Quarto's default engine is lualatex, and a half-set recipe fails silently — corrects D-016's context, its decision standing).

Round 1 returned 14; the maintainer took defect return #1 on R1 and R2 — README stated Quarto defaults to pdflatex and that STIX needs no installing, both probed false — and T9 repaired six. Round 2's blame-history and prior-review lenses were clean; the diff-bug lens returned 12, none reaching the return floor. Follow-up: R3+N7 (stix is obsolete and outside a default TinyTeX, a GP3 tension) and a clustered M33 suite-hardening row (R4, R6, R8, R12, N5, N6, N9). Rejected: R5, R11, R14, N1, N8, N11, N12.
