- 2026-08-16 (M01): Reviewing an escape table character by character cannot establish that a character survives — the failure depends on how the consumer *reads* the argument. Only compiling each one settles survival; only typesetting the result settles that it prints.
- 2026-08-16 (M01): Pandoc consumes one backslash level in a quoted span-attribute value (`\!`→`!`, `\\`→`\`, `\"`→`"`), so an escape defined at the filter layer is not what the author types.
- 2026-08-16 (M01): Inside `\index{}` LaTeX reads under `\@sanitize` (`\` becomes catcode 12, so `\{` escapes nothing), and hyperref rewrites the argument at its first `|` before makeindex runs. Neither is discoverable from the character alone.
- 2026-08-16 (M02): makeindex parses `!` and `@` inside the encap argument too, so a cross-reference target needs the same quoting an entry key does — braces do not shield it. An unquoted `!` there is rejected outright, which under Quarto means a failed build rather than a lost entry.
- 2026-08-16 (M02): A probe that uses the same value in two slots cannot tell one slot from two. Vary the values across slots, and assert the count of slots, or the check passes on output that dropped one of them.
- 2026-08-17 (M03): An anchor id must never sit inside content a renderer copies elsewhere — Quarto copies heading inlines into the sidebar TOC, duplicating any id inside. Emit anchors on empty elements adjacent to the copied content; borrowing a container's id makes every new shape (author id, second mark, missing id) another special case.
- 2026-08-17 (M03): `<span id=…>` written inline in markdown is nativized by Pandoc into an AST Span, id visible to filters. A fixture probing genuinely raw HTML must use a `{=html}` block, or it exercises nothing.
- 2026-08-17 (M04): imakeidx's `\printindex` closes the `.idx` file it has just read, so an index printed mid-document silently drops every later `\index` — the entries go to the `.log` and the build stays clean. Its `noautomatic` option skips that close.
- 2026-08-17 (M04): Quarto emits `use_latex_package` as `\@ifpackageloaded{pkg}{}{\usepackage[opts]{pkg}}`, so options never reach a document that loads the package itself; and `\PassOptionsToPackage` registers options on an already-loaded package, which defeats an `\@ifpackagewith` check written to detect exactly that case.
- 2026-08-17 (M05): Quarto renders a book's chapters sequentially in book order, each in its own Pandoc process — `doc.meta.book.render` carries the ordered chapter list and `quarto.project.offset` the page-to-root path, so cross-chapter work needs no guessing about layout, only somewhere to leave data between processes.
- 2026-08-17 (M05): Quarto normalizes a link target — a percent-escaped href a filter emits reaches output unescaped, matching Quarto's own links — so escaping at the filter layer is a no-op rather than a safety net.
- 2026-08-17 (M05): `pandoc.system.make_directory` raises a Lua error rather than returning a failure, so an unguarded call aborts the whole render; the `io.open` beside it returns nil and err, which is why one of the two was guarded and the other was not.
- 2026-08-18 (M08): Quarto wraps a callout, a tabset and a captioned figure in `__quarto_custom_scaffold` divs, so a filter reasoning about "the container the author wrote" is handed a div that exists in no source file — a message naming it is false however correct the rule behind it.
- 2026-08-18 (M08): `doc:walk` on a Pandoc value traverses `meta` as well as `blocks`, so a document-wide walk reports things written in the title or abstract; `Block:walk` visits an element's contents and never the element itself, so a top-level container needs checking directly.
- 2026-08-18 (M09): makeindex keys an entry on its sort field, so `X@X` and a bare `X` are one key — comparing emitted `\index` argument strings to find a collision splits pairs the tool merges, and comparing what each level actually files under is what reads the tool's own view.
- 2026-08-18 (M09): A report that quotes a value the code derived — a fallback filled in where the author wrote nothing — hands them a string they never typed and cannot search for; name the fallback as what it is.
- 2026-08-18 (M10): makeindex swallows a TRAILING null field (`\index{Moles!}` prints as the bare top-level term) while rejecting a leading one outright, so the two empty-level shapes fail in opposite ways and neither is evidence about the other.
- 2026-08-18 (M11): makeindex reads `!` before an encap as part of the encap, not as a level separator — `\index{Cats!|see{X}}` is accepted and prints `Cats`, where a bare `\index{!Cats}` is rejected outright. A null-field rule inferred from one of the two does not transfer to the other.
- 2026-08-18 (M11): makeindex falls back to the SORT key when a level's printed half is empty, so `\index{mmm@!Cats}` silently prints `mmm` as a parent term the author never wrote — accepted, exit 0, no warning. An entry surviving the tool is not evidence it survived intact.
- 2026-08-19 (M12): A filter cannot honestly name the container an author wrote — Quarto hands it `.callout-style-default`, `.panel-tabset` and `.quarto-float` divs no source file contains. Report the position the author can act on and name nothing; the naming is what cost M08 three review returns, not the rule behind it.
- 2026-08-19 (M12): Pandoc 3.10.2's `Block` walk DOES reach a footnote's blocks, so M08's extra `Note` handler now double-counts. A traversal fact recorded as a code comment is a claim about one Pandoc version; re-probe it rather than inherit it.
- 2026-08-19 (M13): The sort-key registry keys on an entry's printed level path, so a new fixture mark whose path matches an existing probe's silently attaches its key to that probe — `entry="Cats!"` turned a neighbouring `entry="!Cats"` probe's `\index{Cats}` into `\index{a@Cats}`. Give a new mark a term no other mark in the file indexes.
- 2026-08-19 (M14): A per-record field that only a warning reads is not a format change. Bumping the store version for it invalidates every OTHER chapter's record, so a single-chapter re-render drops their terms from the book index — a real loss traded for wording. Make such a field optional with a named fallback and leave the version alone.
- 2026-08-22 (M21): A per-chapter record that mixes what the author WROTE with what that chapter CONCLUDED is read in another process as though every field were raw. Three review rounds each produced one defect from that single conflation — the record's range end, then the book's pairing verdict, then the record's role — each repaired on the path it was found and left standing on its sibling. Where a record crosses a process boundary, give the author's own values and a reader's conclusions separate names, or the next fix finds a new field to be wrong in.
- 2026-08-22 (M22): A LaTeX auxiliary file outlives the source that wrote it (`latex-clean: false`, or a failed render), so every command the filter writes into one is an input to the NEXT render — a render whose marks no longer define it. The `.aux` is read at `\begin{document}`, so a stand-in only acts from the preamble; the `.ind` is read later at `\printindex` and carries `\quartoindexlocator`, which the `.aux` stand-ins do not cover.
