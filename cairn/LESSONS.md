- 2026-08-16 (M01): Reviewing an escape table character by character cannot establish that a character survives — the failure depends on how the consumer *reads* the argument. Only compiling each one settles survival; only typesetting the result settles that it prints.
- 2026-08-16 (M01): Pandoc consumes one backslash level in a quoted span-attribute value (`\!`→`!`, `\\`→`\`, `\"`→`"`), so an escape defined at the filter layer is not what the author types.
- 2026-08-16 (M01): Inside `\index{}` LaTeX reads under `\@sanitize` (`\` becomes catcode 12, so `\{` escapes nothing), and hyperref rewrites the argument at its first `|` before makeindex runs. Neither is discoverable from the character alone.
- 2026-08-16 (M01): A green suite is evidence about what it covers, not about the code. Three review passes each found defects the passing suite did not reach; probe the interaction that actually broke, not a simpler cousin of it.
- 2026-08-16 (M01, consolidated M14 from M06 and M08): Prove a check discriminating by reverting the fix and watching it fail — a passing check may be one that cannot fail (three here passed against a filter emitting no sort field at all, a control implied by earlier assertions, and a rule its own comment disclaimed), and a grep matching any instance of a warning fences nothing. Commit the fix first: `git checkout -- <file>` inside the probe restores HEAD and destroys uncommitted work. M15 adds a third shape: the check's own pattern quietly matching less than it reads as — `re.findall` over alternating groups returns `''` for the branch that did not match, and `\seealso?` requires the literal `seeals`. M16 adds a fourth: the check's DOMAIN silently emptying — a scan reading source out of one named file goes vacuous the moment the definition moves to another, and nothing about it looks different. M17 adds a fifth: the REPAIR for a vacuous domain going vacuous itself — replacing a hand list of fixture filenames with a script that scans five named front-matter keys is the same shape one layer down, while the comment beside it says the hand list is gone. Where a copy has to be complete, hold it against a rendering made where nothing was copied at all. Probe a spliced defect of each kind the check claims to catch, and where the check sweeps a domain, probe the domain moving too. M18 adds a sixth: a grep key shared by two messages counts neither, and a key the run passes but the key-distinctness scan does not receive is held to nothing — every zero-expectation control resting on it then passes vacuously. Pass that scan every key the run uses, never a fixed slice. M23 adds a seventh, one layer up: a scan that pins NAMES and SHAPES in source certifies a property it never asserts — twice here it counted a call or matched an indentation-anchored line while the property was about WHERE the code sat, and a tree breaking it exited 0. Six such gaps surfaced across two review rounds, each only by someone building the broken tree by hand. Where the property is positional, assert it by breaking it and rendering: a render cannot pass a tree whose render fails. And a criterion promising what a checker asserts binds the checker, not the deliverable — M25 adds that such a criterion, greping a file set, is matched by COMMENTS too: a comment quoting the old spelling the criterion forbids fails it as surely as a live call. M25 adds an eighth shape as well: a plant of the wrong KIND. Narrowing six scans from first-match to exactly-one left the probe planting a changed VALUE, which a first-match reader fails on exactly as an exactly-one reader does, so the new clause could have been reverted with the suite green; the defect a count clause needs planted is a second definition. And retiring a pinned count leaves the enumeration it fed unfloored — `find` over an empty directory exits 0, the loop never runs, and the pass line reports success over nothing.
- 2026-08-16 (M02): makeindex parses `!` and `@` inside the encap argument too, so a cross-reference target needs the same quoting an entry key does — braces do not shield it. An unquoted `!` there is rejected outright, which under Quarto means a failed build rather than a lost entry.
- 2026-08-16 (M02): A probe that uses the same value in two slots cannot tell one slot from two. Vary the values across slots, and assert the count of slots, or the check passes on output that dropped one of them.
- 2026-08-17 (M03): An anchor id must never sit inside content a renderer copies elsewhere — Quarto copies heading inlines into the sidebar TOC, duplicating any id inside. Emit anchors on empty elements adjacent to the copied content; borrowing a container's id makes every new shape (author id, second mark, missing id) another special case.
- 2026-08-17 (M03): `<span id=…>` written inline in markdown is nativized by Pandoc into an AST Span, id visible to filters. A fixture probing genuinely raw HTML must use a `{=html}` block, or it exercises nothing.
- 2026-08-17 (M04): imakeidx's `\printindex` closes the `.idx` file it has just read, so an index printed mid-document silently drops every later `\index` — the entries go to the `.log` and the build stays clean. Its `noautomatic` option skips that close.
- 2026-08-17 (M04): Quarto emits `use_latex_package` as `\@ifpackageloaded{pkg}{}{\usepackage[opts]{pkg}}`, so options never reach a document that loads the package itself; and `\PassOptionsToPackage` registers options on an already-loaded package, which defeats an `\@ifpackagewith` check written to detect exactly that case.
- 2026-08-17 (M04): A test runner that pipes its check body to `tee` runs that body in a subshell inheriting `errexit` as it stands at the pipeline — a `set +e` before the pipe (to read PIPESTATUS) makes every exit-status-only check advisory while the run still prints "all passed". M22 adds the one-liner shape: `[ cond ] && fail "…"` makes the PASSING case the script's own non-zero exit, aborting the run with no FAIL line.
- 2026-08-17 (M05): Quarto renders a book's chapters sequentially in book order, each in its own Pandoc process — `doc.meta.book.render` carries the ordered chapter list and `quarto.project.offset` the page-to-root path, so cross-chapter work needs no guessing about layout, only somewhere to leave data between processes.
- 2026-08-17 (M05, consolidated M21 from M15): A later step destroys the artifact an earlier one left, and the check that reads it goes vacuous rather than failing. `quarto render --to pdf` on a book replaces the whole output directory, so an HTML and a PDF artifact of one book never coexist; on a single document it removes the intermediate `examples/<name>.tex`, and a sweep that "skips" that file by basename then sweeps nothing. Copy what a check needs into `$WORK` at the render that produces it and read the copy. M21 adds two more destroyers: a hardening step that deliberately corrupts a record and re-renders one chapter, so the book HTML left at the end of a run is not the state a criterion is about; and the suite itself, which begins by removing `tests/.work`, so two concurrent runs destroy each other mid-flight and the second failure reads as a missing-file defect in the branch. M24 makes the prescription enforced rather than remembered — every render captures, every check reads the copy, and a scan over the suite's own source fails on a working-tree read — but only where the fixture directory is spelled literally: a read reaching it through a shell variable passed that scan unseen, and eleven did.
- 2026-08-17 (M05): Quarto normalizes a link target — a percent-escaped href a filter emits reaches output unescaped, matching Quarto's own links — so escaping at the filter layer is a no-op rather than a safety net.
- 2026-08-17 (M05): `pandoc.system.make_directory` raises a Lua error rather than returning a failure, so an unguarded call aborts the whole render; the `io.open` beside it returns nil and err, which is why one of the two was guarded and the other was not.
- 2026-08-18 (M06): A planted test fixture encoding a filter constant — a store version, a chapter count — silently stops testing its rule when that constant changes: the record is then rejected on version, or the count means something other than "per chapter", and the check still passes. Read the constant from the artifact.
- 2026-08-18 (M06): A manifest's derivation comment is its oracle, so extending the manifest without rewriting the comment leaves the new rows unbacked — and a manifest that borrows another's row order cannot be the independent evidence a check comparing the two claims it is.
- 2026-08-18 (M07): A check that reads an element's TEXT cannot tell which element carries it — a div and a heading render the same label, and only one enters the TOC and the id namespace — so assert the tag, class list and id, not the content alone.
- 2026-08-18 (M08): Quarto wraps a callout, a tabset and a captioned figure in `__quarto_custom_scaffold` divs, so a filter reasoning about "the container the author wrote" is handed a div that exists in no source file — a message naming it is false however correct the rule behind it.
- 2026-08-18 (M08): A warning check that counts occurrences passes while the warning names the wrong element. Three rounds of container-report defects all counted right; assert the identity or kind the message is about, not how many fired.
- 2026-08-18 (M08): `doc:walk` on a Pandoc value traverses `meta` as well as `blocks`, so a document-wide walk reports things written in the title or abstract; `Block:walk` visits an element's contents and never the element itself, so a top-level container needs checking directly.
- 2026-08-18 (M09): makeindex keys an entry on its sort field, so `X@X` and a bare `X` are one key — comparing emitted `\index` argument strings to find a collision splits pairs the tool merges, and comparing what each level actually files under is what reads the tool's own view.
- 2026-08-18 (M09): A report that quotes a value the code derived — a fallback filled in where the author wrote nothing — hands them a string they never typed and cannot search for; name the fallback as what it is.
- 2026-08-18 (M10): A criterion inherited from template boilerplate can promise away a defect the milestone's own Scope excludes — "the verify slot passes on a clean checkout" was false before the milestone began and stayed false after it, and two criteria-audit rounds passed it because the audit read the promise and never ran it. M19 adds a second way an audit certifies bad wording: a value's depth is three numbers, not two — what the author wrote, what survives the empty-level drop, and what the ceiling prints — and the number a report held was the middle one while reading as though it named either end, which a two-term vocabulary had no name for and so passed. Enumerate every number a value has before a message names one.
- 2026-08-18 (M10): A check that names the entries it inspects by the text they print goes vacuous under exactly the regression it guards — an entry that kept a cross-reference prints the target too, so it no longer matches the name and the clause passes by not matching. Quantify over every entry and name the exceptions instead.
- 2026-08-18 (M10): makeindex swallows a TRAILING null field (`\index{Moles!}` prints as the bare top-level term) while rejecting a leading one outright, so the two empty-level shapes fail in opposite ways and neither is evidence about the other.
- 2026-08-18 (M11): When one list is realigned against another, a fact about what the AUTHOR wrote must stay measured in the written list. Reading "the last level a key was declared for" off the realigned list turned positional filler into a declaration — and only for entries that needed no realignment at all, so every fixture built from the shapes the change was about passed.
- 2026-08-18 (M11): A fixture built only from the shapes a milestone changes cannot catch a regression in the shapes it leaves alone. Every M11 entry had an empty level, so a defect reachable only WITHOUT one was invisible to thirteen new checks and to the revert probe. Put the untouched shape in the fixture and assert what must not change. M18 adds the mirror, on a milestone whose own subject was two reports contradicting each other: a new report placed ABOVE the branch that drops a value fires for values that were dropped, and every fixture sat at the one depth where the new report cannot fire, so fourteen new checks and a three-lens review of the criteria never reached it. Ask which branch a new report belongs on, and build one fixture at the depth where it must stay silent.
- 2026-08-18 (M11): makeindex reads `!` before an encap as part of the encap, not as a level separator — `\index{Cats!|see{X}}` is accepted and prints `Cats`, where a bare `\index{!Cats}` is rejected outright. A null-field rule inferred from one of the two does not transfer to the other.
- 2026-08-18 (M11): makeindex falls back to the SORT key when a level's printed half is empty, so `\index{mmm@!Cats}` silently prints `mmm` as a parent term the author never wrote — accepted, exit 0, no warning. An entry surviving the tool is not evidence it survived intact.
- 2026-08-19 (M12): A filter cannot honestly name the container an author wrote — Quarto hands it `.callout-style-default`, `.panel-tabset` and `.quarto-float` divs no source file contains. Report the position the author can act on and name nothing; the naming is what cost M08 three review returns, not the rule behind it.
- 2026-08-19 (M12): Pandoc 3.10.2's `Block` walk DOES reach a footnote's blocks, so M08's extra `Note` handler now double-counts. A traversal fact recorded as a code comment is a claim about one Pandoc version; re-probe it rather than inherit it.
- 2026-08-19 (M12): A hand-derived count over a fixture was wrong on two successive passes here (15, then 17, where the render says 20). Where a check asserts a count the author derived by eye, make the comment show its arithmetic — the sum is what a reader can check. M17 adds the inverse: a pattern-based rename over source lands in PROSE — qualifying every use of a moved definition rewrote the English word in "the outcome they describe differs", because `describe` is also a function name. Bound such a pass with a command rather than by eye: strip the added prefix from every comment line and require the multiset to equal the base's. M24 shows what an unbounded pass costs: rewriting 238 read sites falsified six comments, one by inverting the very rationale of the helper the milestone added, and they surfaced across three review rounds — three of them only after the first repair had looked complete.
- 2026-08-19 (M13): A pinned count of a filter's warning literals cannot see a message split across `..` — the literal count and the call count both stay the same. Only joining every literal in the call's message expression reads what such a scan claims to compare.
- 2026-08-19 (M13): The sort-key registry keys on an entry's printed level path, so a new fixture mark whose path matches an existing probe's silently attaches its key to that probe — `entry="Cats!"` turned a neighbouring `entry="!Cats"` probe's `\index{Cats}` into `\index{a@Cats}`. Give a new mark a term no other mark in the file indexes.
- 2026-08-19 (M14): `find … -print0 | xargs -0 grep -l` kills a `set -euo pipefail` suite with no FAIL line at all when any batch matches nothing — grep exits 1, xargs 123, and the run simply stops mid-check. Use one recursive `grep -rl --include=` with its no-match exit absorbed, and let the comparison that follows fail on the empty result.
- 2026-08-19 (M14): A per-record field that only a warning reads is not a format change. Bumping the store version for it invalidates every OTHER chapter's record, so a single-chapter re-render drops their terms from the book index — a real loss traded for wording. Make such a field optional with a named fallback and leave the version alone.
- 2026-08-22 (M20): An oracle that derives its expectation from the artifact under test is blind in exactly the dimension it derives. Hand-written expected strings here were byte-identical under the defect that broke the feature past page nine, so they certified it; replacing them with a derivation from the same render's `.ind` and `.aux` then hid a wrong-page registration, because expectation and artifact moved together. A derived oracle still needs one fact stated independently of the artifact — here, which page each mark actually sits on.
- 2026-08-22 (M21): A per-chapter record that mixes what the author WROTE with what that chapter CONCLUDED is read in another process as though every field were raw. Three review rounds each produced one defect from that single conflation — the record's range end, then the book's pairing verdict, then the record's role — each repaired on the path it was found and left standing on its sibling. Where a record crosses a process boundary, give the author's own values and a reader's conclusions separate names, or the next fix finds a new field to be wrong in.
- 2026-08-22 (M22): A LaTeX auxiliary file outlives the source that wrote it (`latex-clean: false`, or a failed render), so every command the filter writes into one is an input to the NEXT render — a render whose marks no longer define it. The `.aux` is read at `\begin{document}`, so a stand-in only acts from the preamble; the `.ind` is read later at `\printindex` and carries `\quartoindexlocator`, which the `.aux` stand-ins do not cover.
