- 2026-08-16 (M01; extended M114): Inside `\index{}` LaTeX reads under `\@sanitize`: `\` becomes catcode 12, so `\{` escapes nothing. Hyperref rewrites the argument at its first `|` before makeindex runs. Neither is discoverable from the character alone. A contents line drops `\index` with `\@gobble@som`, not `\@gobble`, so compare `\index` with its document meaning.
- 2026-08-19 (M13; extended M56, M57): The sort-key registry keys on a mark's printed level path, so a new fixture mark needs a term no other mark in the file indexes. Quarto also injects a `labels:` map into every document. Render a fixture declaring none before claiming a top-level key, and namespace it (`index-labels:`). Quarto's schema rejects a non-string `lang:` before the filter runs. What the host rejects is not yours to guard.
- 2026-08-24 (M30; extended M33, M100, corrected M108): A PDF's text layer does not return what the source carried. A T1 font extracts `'` and `` ` `` as curly quotes and a `,` beside the delimiter comma as `„`. Typst on Quarto 1.5.52 maps `fi` to `ﬁ` and `!!` to `‼`, which the Typst reader folds in NFKC and `typstindex.py pages` does not. Compare in NFC, and build expected rows from the typesetting fact, not from the artifact under test.
- 2026-08-25 (M36): Python's `str.isdigit()` is true of digits in EVERY script and `int()` reads them, so a guard written as `level.isdigit()` takes `'٣'` as level 3 — a value no caller writing the suite's own specs by hand can have meant. A guard over a hand-written domain names the spelling it accepts (`isascii() and isdigit()`), never the language predicate that happens to sit near it.
- 2026-08-25 (M37): bash suspends errexit inside a subshell in an `&&`/`||` list even when the subshell sets `set -e` itself, so `( set -eo pipefail; f ) && rc=0 || rc=$?` runs `f` shielded and is green on the defect it tests for. Background the subshell and read its status with `wait`: only `wait` sits in the `&&` list, and the call runs unshielded.
- 2026-08-25 (M37): under `set -u`, bash 3.2 (macOS, what this repo runs) errors on `"${A[@]}"` for an empty declared array, where bash 4.4 and later expand it to nothing. An argument resting on that behavior holds on one shell only, so argue it from something the check pins, such as self-test plants that each name one of the listed lines and could not go red over an empty list.
- 2026-08-25 (M38; extended M073, M080, M081): When a change narrows the set a check or rule covers, the messages that name that set go false in silence. A grep key on a stable tail cannot see it: three green rounds shipped a report telling authors to mark a term they had marked. Re-read every message and comment that enumerates the set, and pin the clause that varies. Fixing one false count on a page leaves the others, so re-read them all.
- 2026-08-26 (M39): `tests/scans/m15-joined-messages.py` balances parentheses from every `warn(` in raw Lua source, comments included, so a comment holding a bare `warn(` swallows the rest of the file and the next file's messages. Only `--self-test` caught it, because its moved tree reorders the files. In prose about the call, write `warn()`.
- 2026-08-26 (M41; extended M44, M45, M52): A residue sweep that greps a page's markup for a plumbing string goes false once a page shows that string as content. Ask the parsed page instead. Flattening whitespace misses markup inside prose (a blockquote's `>` mid-sentence), so strip wrappers per line first. Give each failing shape its own message, and plant a page with two. A copy of the sweep in another module does not inherit a fix.
- 2026-08-26 (M42): Actions fields do not mean what their names say. `github.ref_name` is the tag on a tag push, so gate a deploy on `github.ref`. A job-level `permissions:` replaces the workflow's, so restate each scope. A workflow-level `concurrency:` serializes every branch. `quarto install tinytex` gets a 403 from the API in parallel runs unless given the token. A bare `on: push` matches tags too, so keep a probe commit under `refs/probes/*`.
- 2026-08-26 (M43; extended M51): An old Quarto's toolchain is not today's in miniature. Quarto 1.4.549's TeX installer fails on `imakeidx.sty` against today's TeX Live, so install packages with the runner's TinyTeX on every leg. `tlmgr` is not on PATH, refuses to install before `update --self`, and `mirror.ctan.org` can give two jobs two mirrors, so name the repository. Under `pipefail`, `$(find ... | head -1)` fails the step without `|| true`.
- 2026-08-26 (M43; extended M45, M106): A GitHub Actions job that reports over partial results needs `if: always()`, since `needs:` gates on success. A step that must report past an earlier red step needs `if: ${{ !cancelled() && steps.<render>.outcome == 'success' }}`, and only a probe expecting red shows it skipped. Under `set -e`, write a reader's diagnostics to stderr, and print its domain-size line before the verdict.
- 2026-09-03 (M073): bash reads a script lazily by byte offset, so editing `tests/run-tests.sh` while a run is in flight corrupts that run's parse: a leg failed, then the shell reported a syntax error at a line the file no longer had. Batch edits until the run ends, a long wait included.
- 2026-09-07 (M082; corrected M117): `tests/htmlindex.py` subclasses `HTMLParser`, whose internals move between Python versions (3.12 gives `set_cdata_mode` a keyword-only `escapable=`). The suite runs 3.9 here and 3.12 in CI. Take an override's arguments with `**kwargs`, and probe the reader on the oldest and newest Python. `/usr/local/bin/python3` (3.14.6, no PyYAML) comes first on PATH and stops the suite, so run it with `PATH=/usr/bin:$PATH`.
- 2026-10-19 (M115): An edit a filter makes to a Quarto float's content changes what Quarto does with it later. A wrapper merged layout cells, a label joined to an image cell kept a width Quarto drops, and a wrapper around a code cell's output Div stopped its unwrap. The index read right each time, so check the layout against an unmarked twin of the float.
- 2026-10-20 (M116): A new fixture registers beyond its suite section. A `.qmd` under `examples/` that writes `see=` or `see-also=` needs a row in M14's dangling-count corpus. That corpus greps each file alone, so a shared include body counts as a fixture. Every top-level `examples/*.qmd` needs a line in `site/gallery.yml`. Each new `warn()` literal moves `warn-distinct.py`'s pinned count. Write twins in full, held equal by `derive_labels_twin`.
- 2026-10-20 (M117): A change to what a back-end prints for a degenerate shape breaks other milestones' plants whose want strings quote the old output. M117 broke the M099 dropranges and M098 alt-kept plants, a suite run each. Before the first run, grep the self-tests for want strings resting on the old behavior. pdftotext opens each page after the first with a form feed, so turn `\f` into a newline before an exact-line match.
- 2026-10-20 (M118): Typst 0.15.1 fails a compile whose `while` loop passes 10,000 iterations. A loop in emitted Typst whose count grows with the document is therefore a `for` over a bound with an early `break`. A rewrite moves the plants whose substitution text names the old code. Apply every plant's substitution to the new file by script before the first run (M098's `xreflink` stopped M118's).
- 2026-10-20 (M119): A Typst label copied at layout time, by an outline or a list, never shows in the `.typ` file. Read it with `quarto typst query <file>.typ metadata`, which lists the copies. Quarto writes that JSON to stderr. A Typst element keeps one label, so a label element that ends a heading's line loses its label to the heading's own, written after it.
- 2026-10-20 (M120; extended M122): Expected rows a program builds meet the suite's ORACLE RULE only where a hand-stated rule holds every field the check compares. M098-AC8's held `typstcheck.derived_entries`' terms, not its references, so read it before reusing a derivation. A check that keeps a regex match holds the match, not the line. Python also splits lines at a bare `\r`. Pick lines by pattern, then compare each whole line.
