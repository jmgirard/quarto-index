# M42: GitHub Actions renders the site and publishes it to Pages

**Status:** done (2026-08-26, PR #42 https://github.com/jmgirard/quarto-index/pull/42)

**Goal:** A GitHub Actions workflow renders the site with the toolchain it installs and publishes it to GitHub Pages from the default branch.

**Outcome:** `.github/workflows/pages.yml`, the repo's first workflow. Build job on every branch: Quarto pinned to 1.10.18 and TinyTeX (which carries `makeindex`; the site build reaches no further — not `pdftotext`, not the STIX font), the render piped to `tee` under `pipefail`, then `sitecheck.py rendered` and `pagescheck.py built` before `upload-pages-artifact`. Deploy job gated on `github.ref == refs/heads/<default>`, carrying the `pages` concurrency group. `tests/pagescheck.py` adds four readers: `pin` (integer-tuple compare against `quarto-required`, read out of the Quarto setup step), `built` (the completeness guard the workflow runs), `url` (README, the site entry page and `SITE_BASE_PATH` against the URL the `origin` remote implies), `contains` (an unpacked Pages artifact against a reference render). `SITE_BASE_PATH` is now `quarto-index`, the value M40 left for this milestone. Post-merge the first deploy ran green and https://jmgirard.github.io/quarto-index/ answers 200, its inner pages and a gallery PDF with it.

**Decisions:** D-024 (actions by major tag, Quarto pinned exactly). Milestone-local: `actions/configure-pages` is not used — the site makes only relative links, and that step would have failed ahead of the render while Pages was off.

**AC4 probes:** the five planted-defect branches were deleted 2026-08-26 and their commits kept under `refs/probes/`, outside `refs/heads` and `refs/tags` — reachable and safe from GC, absent from the branch and tag listings, and not matched by `pages.yml`'s bare `on: push`. Fetch with `git fetch origin 'refs/probes/*:refs/probes/*'`; each ref is an annotated object naming its plant and its run. `m042-badsource` 50806f3 (a nonexistent include, fails at render, runs/33016927676) · `m042-nooutput` 41072c9 (`output-dir: _site-elsewhere`, fails at the tracked-page step, runs/33016929230) · `m042-droppage` 6e41ffc (`build_gallery.py` loops over `fixtures[:-1]`, fails at the completeness step, runs/33016930697) · `m042-badpin` 0c3dcea (pin 1.10.999, fails at install, runs/33016932872) · `m042-pipeline` ff2a3bd (renders `nosuchdir` inside the `tee` pipeline, fails at render, runs/33016933334). All five sit on c144320, the post-review-fix branch commit.

**Review:** three-lens fan-out; blame-history and prior-review clean, [O] diff-bug returned 14 ranked findings, none failing a criterion. Ten fixed on the branch: the deploy gate read `ref_name`, so a tag named after the default branch would have published; the deploy job's own `permissions` dropped `contents: read`; the pin matched any indented `version:` line; a bare major passed as a pin and a quoted pin failed; AC5's grep missed C-quoted paths; and five plant gaps — AC5's three clauses, the unparseable remote, the reference side of the directory clause, and a floor case reusing a copy an earlier case had mutated. Two rejected: the base-path change is right, and D-011 refuses the source-shape scan that would bind the workflow's own steps, the probe runs being that evidence. Four filed on the suite-hardening candidate row.
