# M49: A PDF render builds every index the document declares

**Status:** done (2026-08-28, PR #50 https://github.com/jmgirard/quarto-index/pull/50)

**Goal:** The LaTeX back-end stops folding every declared index into one, and a PDF render prints each declared index with its own entries.

**Outcome:** `qi_indexes.reset` folds for an HTML book alone (`title` and `scope_phrase` follow). `latex.lua` gained `index_command` (bare `\index` for the default index, `\index[<name>]` for a named one) and `escape_title`, and namespaces `contested_keys` and `principal_keys` per index, the ordinal counter left document-wide. `index.lua` writes `\makeindex[intoc[,noautomatic]]` for the default index and one `\makeindex[intoc,name=,title={…}]` per named one, loads imakeidx with no package-wide option, and wraps the default index's `\printindex` in an `\ifcsname`-guarded group setting `\imki@disableautomatictrue` so its entry file stays open; one `\printindex` per index rides M38's `place_index` map. `report_below_marker` counts `\index[<name>]` commands standing below their own index's surviving marker. The begin-document imakeidx guard was flipped: it fires on a preloaded `noautomatic` in a document declaring more than one index. New readers: `tests/namedpdf.py` (entries, cells, reports) over a captured PDF and LaTeX log; `pdfindex.read` gained a `stop` bound and `indexdump.py pdf` a matching argument. `examples/named-indexes.qmd` gained the four below-marker cells and all four per-index judgements written wrongly in both indexes; M50's `folded` clause became `split`. Docs: `site/named-indexes.qmd` rewritten in three sections; `site/books.qmd` and `examples/book/_quarto.yml` scoped to the HTML book. Suite 406 checks, self-test 790.

**Decisions:** D-031 — a named index after the first is built by imakeidx under TeX's restricted shell escape, and the condition is documented rather than detected (annotates GP2).

**Review:** One round, no returns; all six criteria met with fresh evidence. Blame-history and prior-review found nothing; diff-bug reported ten — three fixed at the gate (a code comment claiming the below-marker report covers the default index, docs silent on the per-index side files imakeidx leaves beside the project, and a docs sentence introducing the fixture without saying its judgements are deliberately wrong), six filed, one rejected. No lesson added or retired.
