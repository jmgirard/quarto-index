# M082: The id census stays out of content the page does not render as markup

**Status:** done (2026-09-07, PR #82 https://github.com/jmgirard/quarto-index/pull/82)

**Goal:** Two shapes whose content a browser does not render as page markup are read the way a browser reads them in ordinary HTML — a `template` element's contents, which a browser parses into a fragment of its own, and a `script` element's escaped and double-escaped states — and the fixture gains the case for an `id=` on a raw-text element's own opening tag.

**Outcome:** `note_raw` in `_extensions/index/modules/html.lua` counts `template` depth rather than claiming inside one, so an `id=` in a template's content is claimed however deeply the templates nest — never; a `</template>` inside a comment closes nothing, an unclosed `template` leaves the rest of the raw string unclaimed, and the element's own opening tag still claims. A new `script_end` carries the three script escape states: a `<!--` opens an escaped run (entered two characters in, so a `<!-->` or `<!--->` ends the run it opens), a nested `<script>` doubles it, the first `</script>` after that returns it to escaped, and a `-->` returns either run to data. `tests/htmlindex.py` learned both readings and now reads every `</script` shape as a browser does — `</ script>`, `</scriptx>`, `</script/>`, `</script id=zz>` — its cdata scan loosened and its end-tag decision taken in the reader; `<template/>` opens a template there too. Twelve fixture marks in `examples/id-collision.qmd` with their M079-AC1 expectation rows, four `--self-test` plants (one per repair clause), five replaced M079-AC5 claim rows, the skipped-elements row quoting all seven element names, a new M082-AC5 section holding `CHANGELOG.md` to five rows of its own, and a three-sentence `phrase-absent` list. KI256, KI258, KI259 and KI262 struck.

**Decisions:** none.
