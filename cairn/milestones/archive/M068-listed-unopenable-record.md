# M068: A record that is listed and cannot be opened is not read as one that was never written

**Status:** done (2026-09-02, PR #68 https://github.com/jmgirard/quarto-index/pull/68)

**Goal:** In an HTML book, a chapter's sidecar record whose filename appears in the store directory's listing and which cannot be opened sends the building chapter to that chapter's own source, as an opened-and-unusable record already does, rather than being read as a record that was never written.

**Outcome:** `store_directory_unusable` in `_extensions/index/modules/book.lua` replaced by `store_probe`, a lazy per-directory memoized listing whose returned test answers "was this record written" for one record path; `store_read` consults it for each record `io.open` cannot open, and an affirmative answer takes the existing opened-and-unusable branch, so the chapter is recovered from its own source and reported by the existing could-not-be-read wording. The evidence is the record's filename among the entries of its OWN directory rather than the store's top level, because a chapter in a subdirectory keeps its record in a matching subdirectory and two chapters of one filename share a record basename. D-043's directory-level test survives whole as the same probe's `lost` branch, and that answer is now handed down a directory chain, so an unlistable store directory puts a record at any depth out of reach rather than only one sitting directly in it. A record whose name no listing carries is absent exactly as before, so a first render and a tree with no store are untouched. Suite: the `m068-dangling` fixture (a dangling symlink at a record path, re-asserted dangling and listed around every render), a name-absent control in two legs, two nested legs over a copy of `examples/book` whose `sub/two.qmd` keeps its record a level down, and seven `--self-test` plants — 605 checks plain, 1140 with `--self-test`. Author-facing prose in `site/books.qmd` and `CHANGELOG.md`; two pinned claim rows became four and M063-AC6's guard moved 21 → 23.

**Decisions:** D-044, extending D-043's trigger from the store directory to the record file and accepting that a file merely named like a record and unopenable counts as written (KI224).

**Review:** two passes, three-lens fan-out each. Pass 1 returned the milestone at the merge gate on F1 — the `lost` answer not reaching a record in a store subdirectory, a regression against the pre-branch behavior — with F2/F3/F5 (its missing fence and the prose that overstated it) and F4/F7 (suite hygiene) fixed alongside, and F6 rejected as verified by hand. Pass 2 verified all six criteria on fresh evidence, consistency gate clean; the blame-history and prior-review lenses found nothing and the diff-bug lens returned eight findings, none meeting the return floor: G1/G2 (the probe reads an absent record as written when the store directory is missing and `.quarto` itself cannot be listed — unreachable, quarto refuses to render both shapes) routed to KI226, G4-G7 to the suite candidate rows, G3/G8 rejected.
