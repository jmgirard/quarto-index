# M079: An author-written mark id never leaves two elements sharing it

**Status:** done (2026-09-06, PR #79 https://github.com/jmgirard/quarto-index/pull/79)

**Goal:** An author-written id on an index mark never leaves two elements of one page carrying that id, so every index locator lands on the element its author marked.

**Outcome:** `taken_identifiers` (`html.lua`) now counts carriers rather than noting them, and walks a raw HTML string as markup — an `id=` counts where it is an attribute of a tag, stepping over comments and over `script`/`style` character data, reading a quoted value as a value. `assign_anchors` refuses a mark's author id another element carries and mints `qi-mark-<n>` instead; the author's element is never renamed. A mark that files a locator outranks a cross-reference mark for a shared name, and two of a kind are settled by document order. Cross-reference marks are tagged by the Span pass and yield too, staying `anchorless` so the minted id never becomes a locator. `relocate_heading_anchors` reads a mark's own id as well as the pending tag, so an untagged mark's author id still leaves a heading. Each yield draws one report — two wordings, locator and cross-reference. `tests/fragments.py resolve` now holds a fragment's target to exactly one element, and `tests/epubcheck.py unique` reads a publication for repeated ids and non-unique index-link targets. `examples/id-collision.qmd` carries 22 hand-derived marks; `site/html.qmd` is held to 14 pinned claim rows.

**Decisions:** two milestone-local: a cross-reference mark yields a contested id and is reported in a wording of its own; a locator-contributing mark outranks a cross-reference mark for a shared name whichever is written first. D-056 (cross-cutting) supersedes the two D-055 sentences this work falsified.

**Review:** three rounds, three fresh-context lenses each. Two defect returns (an `id=` in an HTML comment counted as a carrier, killing an author's link; then the comment cut swallowing a raw string's tail, and an untagged heading mark no longer relocating) and one amendment return (AC3's minted-id clause, false of a mark whose heading anchor relocates). Round 3: all six criteria green, 7 findings, blame and prior-review lenses zero. X1 — a `script`/`style` element aborting the census walk, so a mark keeps a contested id silently — was reproduced and is real, but falsifies no criterion, AC1 quantifying over the fixture rather than over a rendered page. At the thrash threshold the maintainer chose descope: no fourth round, the code defects recorded as KI254/KI255 with candidate rows, and the shipped pages narrowed to state what the census misses. Retired M03's anchor-in-heading lesson: the AC1 leg now sweeps every heading on the page and fails on the mistake it warned about, and DESIGN.md's architecture slot owns the remedy half.
