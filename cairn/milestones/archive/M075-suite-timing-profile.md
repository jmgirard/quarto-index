# M075: The suite reports where its own time goes

**Status:** done (2026-09-04, PR #75 https://github.com/jmgirard/quarto-index/pull/75)

**Goal:** A full acceptance run states its wall clock per section, so the next change aimed at the run's cost is aimed by measurement rather than by assumption.

**Outcome:** `tests/suitescan.py` gained a `sections` mode reporting the 154 banner headings inside `run_all_checks` over the suite's own tracked source, refusing a heading that repeats, carries a tab, takes the reserved `unattributed` label, or cannot be read from its block. `tests/run-tests.sh` opens a timed section at each of its 155 banner sites — the calls generated from that enumeration, never hand-placed — writing `heading<TAB>seconds` rows and one measured setup row to `tests/.work/timing.tsv`, then holds the row set to the scanner's and the seconds to the run's own clock, and prints the fifteen slowest before the passing line. Whole-second timestamps from `date`; the setup window is measured rather than derived, so a lost row shows as a gap instead of being absorbed. KI241-KI245 record the five execution couplings that block running the suite's legs in parallel, and the parallel-legs candidate row now points at them. Measured: a plain run is flat (61s of 461s in its slowest section); what cost exists is the self-test plants, two sections carrying 1019s of a 1770s `--self-test` run and 8s each without it.

**Decisions:** none cross-cutting. Two implement-gate choices are in the work log with their falsifiers: whole-second timestamps over a sub-second clock, and measuring the setup window rather than deriving it as the remainder.

**Review:** three-lens fan-out. Blame-history and prior-review found no regressions (one duplicate of F3). Diff-bug: twelve findings. Fixed on the branch and re-verified green — F1 a banner block whose first comment line is empty was silently dropped from the timing domain; F2 `sort | head` could SIGPIPE a fully green run into a bare exit 141; F6 the sections mode died under an ASCII locale; F8 a `--5` row traced back instead of failing cleanly; and the print header counted the setup row as a section. F3 accepted as KI246; F4, F5, F7, F9, F10 and F11's fragment headings deferred to the check-discrimination candidate row; F12 rejected. Graduated at hygiene: `check-design.md`'s pipefail lesson gained M075's SIGPIPE mirror image.
